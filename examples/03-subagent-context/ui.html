03 Subagents and explicit context

Real Task/Agent spawning via the Claude Agent SDK — not the hand-rolled coordinator from example 02. Two research subagents run in parallel and hand their full, sourced findings (not just the claim text) to a synthesis subagent, so every sentence in the final report can be traced back to a URL or a page number.

The three subagents — scoped tools, nothing inherited

  • web-searchtools: WebSearch only
  • doc-analysistools: Read, Grep only
  • synthesistools: none — writes from what it's given
